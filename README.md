# O2C Orchestration SaaS

Order-to-Cash (O2C) Orchestration SaaS platform built with modern web technologies, dynamic motion choreography, and high-performance interactive 3D visual experiences.

## Tech Stack
- **Framework**: Vite + Vanilla JS / Modern DOM
- **3D & Graphics**: Three.js, Postprocessing
- **Motion & Animations**: GSAP (GreenSock)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
